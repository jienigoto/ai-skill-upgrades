## 这是什么

一个**文档驱动的 AI 技能升级流水线**：每天围绕当日高活跃的 AI 能力，筛选输入边界清晰的方向，产出可直接复用的 Codex SKILL。

## 工作流（每期项目）

```
brief（方向定义） → script（执行脚本） → output/SKILL.md（可复用技能产物）
```

每期产物还包括：`asset-manifest.md`（资源清单）、`render-notes.md`（渲染说明）、`output/github-release-notes.md`（发行说明）。
